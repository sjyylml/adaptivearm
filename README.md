# One-Person Company with Claude Code

利用 AI 工具（Claude Code）以一人之力搭建和运营公司的技巧教学项目。

## 内容概览

- **AI 替代多岗位**：前端、后端、DevOps、QA、技术文档
- **自动化工作流**：CI/CD、Hooks、自定义 Skills、MCP 服务器
- **产品开发**：从零到一的全栈开发与部署
- **Agent SDK**：构建 AI 驱动的产品和工具

## 适用人群

独立开发者、自由职业者、小规模创业者。

## 快速开始

```bash
# 克隆项目
git clone https://github.com/sjyylml/one-person-company.git
cd one-person-company

# 查看教学内容
ls docs/
```
